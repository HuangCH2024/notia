# Notia - Free and quality Online Message Board 

![NotiaLogo](../src/NotiaLogo.png)

## About this Porject

Notia is an online open-source web message board that is completely anonymous. Anyone with internet access can come and post. Of course, you can also deploy Notia on your own web server. Notia is completely free.

## Tech Stack

1. Real-time Engine: Supabase PostgREST + WebSockets (Realtime).

2. State Management: React Hooks + Optimistic UI Updates.

3. Interaction Design: Framer Motion + React Draggable + Custom Canvas Engine.

## Deployment Requirements

You need Node.js version 18 or higher, and a registered free Supabase account with services enabled.

### Installation and Setup

1. Run `npm install` to install dependencies.
2. Open `src/assets/components/supabase.ts` and configure your own Supabase information.
3. Run `npm run dev` to start the development server.

### Production Deployment

To deploy the application in production on Windows or Linux:

1. Run `npm run build` to create the production build. This will generate the `dist` folder with optimized files.
2. Deploy the contents of the `dist` folder to your web server.
3. For Windows servers, you can use IIS or a simple HTTP server. For Linux, use Nginx, Apache, or a Node.js server if needed.
4. Ensure your Supabase configuration is set for production environment.



## System Requirements

System requirements for running on a personal computer: Core 2 or newer processor, at least Windows 8 or Server 2012 64-bit, at least 2GB of available memory, and 100MB of available disk space.
